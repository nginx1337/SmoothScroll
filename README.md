# SmoothScroll

Плавная прокрутка колёсиком мыши для macOS 27 (Apple Silicon). Собирается под SDK macOS 27,
поэтому работает как нативное приложение, без режима совместимости.
Живёт в строке меню, без иконки в Dock.

## Как работает

1. Сессионный event tap (`CGEvent.tapCreate`) ловит события колёсика. Он работает
   в отдельном высокоприоритетном потоке, поэтому занятость интерфейса приложения
   никогда не тормозит прокрутку в системе.
2. Каждый «щелчок» колеса поглощается и превращается в плавную анимацию
   (экспоненциальное затухание, ease-out), которую ведёт `CADisplayLink`
   с частотой обновления экрана (60/120 Гц ProMotion).
3. Каждый кадр отправляется маленькое пиксельное событие прокрутки.
   Остаток долей пикселя переносится между кадрами, поэтому итоговое
   расстояние точное и не зависит от частоты экрана.
4. Если во время плавного хода курсор уходит в другое окно, ход останавливается:
   прокручивается только то окно, над которым крутили колёсико. Это можно выключить
   («Останавливать при переходе в другое окно»), тогда остаток уйдёт в окно под курсором.

Что **не** трогается (идёт как есть):
- трекпад, Magic Mouse и любые устройства с уже плавной прокруткой;
- прокрутка с зажатыми ⌘ / ⌃ / ⌥ (масштаб и т.п.);
- собственные синтетические события (помечены `eventSourceUserData`).

## Сборка и установка

Нужны только Command Line Tools (`xcode-select --install`), Xcode не обязателен.

```bash
scripts/build-app.sh
```

Скрипт прогоняет тесты, собирает release-версию и подписывает её
ad-hoc подписью с hardened runtime. Затем:

```bash
cp -R build/SmoothScroll.app /Applications/ && open /Applications/SmoothScroll.app
```

При первом запуске macOS попросит доступ: **Системные настройки → Конфиденциальность
и безопасность → Универсальный доступ → SmoothScroll**. Без него перехват колеса
невозможен. Доступ проверяется каждые 2 секунды: после выдачи перехват включится сам,
а если доступ отозвать, иконка в строке меню сразу покажет предупреждение.

> Ad-hoc подпись меняется при каждой пересборке, поэтому после обновления
> macOS может снова спросить доступ: удалите старую запись «SmoothScroll» из
> списка «Универсальный доступ» и добавьте заново.

## Настройки

Основное доступно прямо в меню значка в строке меню: вкл/выкл, ползунки скорости
и плавности, ускорение и обратное направление. Значок залит, когда прокрутка включена,
и показан контуром на паузе.

Все параметры: меню значка → **Все настройки…** (⌘,). Окно также открывается, если запустить
приложение повторно из Finder или Spotlight. Изменения применяются сразу.

| Параметр | Значения |
|---|---|
| Плавная прокрутка | вкл/выкл (также прямо в меню) |
| Скорость | 20–200 px за щелчок + пресеты |
| Плавность | 30–300 мс + пресеты |
| Ускорение | вкл/выкл и сила |
| Обратное направление | только для мыши, трекпад не меняется |
| Автозапуск | через `SMAppService` (приложение должно лежать в «Программах») |

Внизу окна есть область для проверки прокрутки и кнопка «Сбросить по умолчанию».

## Безопасность

- **Нет сети.** Бинарник не использует сетевые API (проверка:
  `nm -u build/SmoothScroll.app/Contents/MacOS/SmoothScroll | grep -i -E "URLSession|socket|NWConnection"` — пусто).
- **Нет entitlements**, включён hardened runtime.
- **Перехватываются только события прокрутки** (маска `scrollWheel`), клавиатура и
  клики не видны приложению вообще.
- Никаких логов, телеметрии, файлов — только `UserDefaults` (`local.smoothscroll`).
- Все параметры зажаты в безопасные пределы, очередь прокрутки ограничена, защита
  от скачков времени (сон, отладчик) — прокрутка не может «улететь».
- Если система отключит tap (таймаут), он включается обратно автоматически.
- Незавершённый плавный ход сбрасывается при сне дисплея и смене мониторов, поэтому
  он не может «выстрелить» позже.
- Около 700 строк кода — можно прочитать целиком: `Sources/`.

## Иконка

`Resources/AppIcon.icns` генерируется из векторной геометрии, снятой с
`Resources/icon-source.png`, поэтому чёткая во всех размерах:

```bash
swift scripts/make-icon.swift
```

## Тесты

```bash
scripts/test.sh
```

23 теста на ядро (`SmoothScrollCore`):
- анимация: точность расстояния на 30–240 Гц, ease-out, смена направления, ускорение
  и его предел, ограничение очереди, мусорные входные данные (NaN, отрицательное время), реверс;
- фильтр событий: трекпад/Magic Mouse и ⌘/⌃/⌥ не трогаются, собственные события не
  перехватываются повторно, склеенные щелчки сохраняют величину (с ограничением).

## Удаление

Выйти из меню → удалить `/Applications/SmoothScroll.app` → убрать запись из
«Универсального доступа» → `defaults delete local.smoothscroll`.
