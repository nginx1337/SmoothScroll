# Безопасность и приватность SmoothScroll

## Что SmoothScroll делает с вашими данными

- **Всё остаётся на Mac.** В приложении нет сетевого кода, аналитики, телеметрии и учётных записей. Проверка: `nm -u build/SmoothScroll.app/Contents/MacOS/SmoothScroll | grep -i -E "URLSession|socket|NWConnection"` — пусто.
- **Только прокрутка.** Event tap подписан лишь на события колёсика (маска `scrollWheel`): нажатия клавиш и клики приложению не видны вообще.
- **Никаких файлов и логов.** Хранятся только настройки в `UserDefaults` (`io.github.nginx1337.smoothscroll`).
- **Прокрутка не может «улететь».** Все параметры зажаты в безопасные пределы, очередь прокрутки ограничена, есть защита от скачков времени (сон, отладчик). Незавершённый ход сбрасывается при сне дисплея и смене мониторов, поэтому не может «выстрелить» позже.
- **Перехват восстанавливается сам.** Если система отключит tap (например, по таймауту), он включается обратно автоматически.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Универсальный доступ | Перехватывать события колёсика и отправлять плавные |

Запись экрана, доступ к файлам и полный доступ к диску **не нужны**.

## Сборка и подпись

- Приложение собирается с hardened runtime и без entitlements.
- Сторонних зависимостей нет: `Package.swift` подключает только системные фреймворки.
- Из бинарника удаляются отладочные символы, поэтому пути сборки (имя пользователя, папки) в приложение не попадают.
- Около 1100 строк кода — можно прочитать целиком: `Sources/`.
- Сборка из репозитория подписана ad-hoc. Для распространения нужна подпись Developer ID и нотаризация.

## Как сообщить об уязвимости

Не публикуйте подробности в открытых issues. Воспользуйтесь закрытым сообщением об уязвимости на GitHub (вкладка **Security → Report a vulnerability**). Опишите шаги воспроизведения и версию macOS.
